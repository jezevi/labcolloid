LabColloid — приложение для iPhone без App Store

1. Зайдите на github.com, нажмите «New repository», назовите, например, labcolloid, поставьте Public, создайте.
2. На странице репозитория нажмите «uploading an existing file» и перетащите ВСЕ файлы из этой папки (index.html, sw.js, manifest.webmanifest, три иконки icon-*.png, icon.svg). Нажмите «Commit changes».
3. Settings → Pages → Source: «Deploy from a branch», ветка main, папка /(root) → Save.
4. Через 1–2 минуты ссылка появится на той же странице: https://ВАШ-ЛОГИН.github.io/labcolloid/
5. Откройте ссылку в Safari на iPhone → «Поделиться» → «На экран “Домой”». Один раз откройте иконку при включённом интернете, дальше приложение работает без сети.
